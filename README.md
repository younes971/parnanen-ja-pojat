# Pärnänen & Pojat

Pärnänen & Pojat on vintage-kirjoituskoneisiin keskittyvä verkkokauppa.

Sivusto sisältää etusivun, tuotesivun sekä yrityksen esittelysivun. Tuotteiden tiedot ja kuvat haetaan Sanity CMS:stä

## Ominaisuudet

- Responsiivinen käyttöliittymä
- Tuotteet haetaan Sanity CMS:stä
- Tuotekuvat
- Navigointi eri sivujen välillä
- Aktiivisen sivun korostus navigaatiossa

## Käytetyt teknologiat

- Next.js
- TypeScript
- Sanity CMS
- React

## Projektin käynnistys

npm install
npm run dev
